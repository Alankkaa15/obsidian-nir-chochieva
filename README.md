# Хранилище НИР: искусственный интеллект в обучении РКИ

**Автор:** Чочиева Алана Асланбековна, магистратура, направление «Русский язык как иностранный»
**Дата начала работы:** 5 октября 2026 года

## Тема исследования

Рабочая тема: «Использование инструментов искусственного интеллекта в обучении русскому языку как иностранному».

Меня интересует, как чат-боты и другие сервисы на основе ИИ могут помогать иностранцам учить русский язык: становиться собеседником для практики говорения, давать обратную связь на письменные работы, помогать преподавателю готовить материалы. Отдельный вопрос: какие риски это несёт и как встроить ИИ в урок так, чтобы он помогал, а не заменял работу студента. Тема будет уточняться вместе с научным руководителем.

## Как устроено хранилище

- 00_Inbox: быстрые идеи и мысли, которые нужно разобрать позже.
- 01_Literature: заметки по источникам, одна заметка на одну книгу или статью.
- 02_Notes: мои собственные мысли по теме, связанные ссылками. Ядро хранилища.
- 03_Projects: проекты с результатом и сроком: план ВКР, статья, доклад.
- 04_Drafts: черновики текстов.
- 05_Output: готовые результаты: тезисы, доклады.
- \_Templates: шаблоны для новых заметок.
- \_Attachments: картинки, схемы и PDF.

Путь знания: идея (00) → источник (01) → своя мысль (02) → проект (03) → черновик (04) → результат (05).

## Теги

- #источник/книга, #источник/документ: тип источника
- #ии/чат-боты, #ии/этика: аспекты ИИ
- #методика/говорение, #методика/письмо: виды речевой деятельности
